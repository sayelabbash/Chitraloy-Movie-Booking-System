# Chitraloy Movie Booking Application

Full-stack movie booking application built with Spring Boot and React.

## Structure
- `backend/` — Java 17 / Spring Boot / Spring Data JPA / MySQL / Spring Security / JWT / Razorpay
- `frontend/` — React 18 / Vite / Tailwind CSS

## Local setup
1. Configure `backend/.env` from `backend/.env.example`.
2. Configure `frontend/.env` from `frontend/.env.example`.
3. Start the backend on port 8081.
4. Start the frontend with `npm run dev`.

Never commit real credentials or secrets.
